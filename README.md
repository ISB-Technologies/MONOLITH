# MONOLITH

**MONOLITH** — концепция открытого модульного стандарта зданий от ISB Technologies. Репозиторий содержит интерактивный браузерный прототип-конструктор и сопроводительную документацию проекта.

> **Статус:** ранний прототип 0.1.0. Геометрия схематична. Приложение не выполняет расчёты несущих конструкций, пожарной безопасности, эвакуации, инженерных систем или геотехнических условий. Не использовать для строительства.

## Онлайн-демо

После включения GitHub Pages: `https://isb-technologies.github.io/MONOLITH/`

## Возможности прототипа

- Профили HOTEL, DATA, RESEARCH, HQ, INDUSTRIAL и SHELTER.
- Параметры этажности, подземных уровней, ширины, глубины, шага сетки и высоты этажа.
- Схематическая изометрическая визуализация с поворотом.
- Слои каркаса, фасада, перекрытий, ядра и подземной части.
- Фасадные варианты GRID, SOLID и GLASS.
- Управление видом: поворот модели кнопкой ⟳ и переключение подписей (Aa).
- Экспорт и импорт проекта в JSON.
- Базовые проверки кратности габаритов шагу сетки и предупреждения о нерассчитываемых аспектах.
- Работа без сервера. Внешние JavaScript-библиотеки не используются; при отсутствии сети применяются системные шрифты.

## Запуск локально

Откройте `index.html` в современном браузере. Для локального HTTP-сервера можно выполнить из корня репозитория:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация в GitHub Pages

1. Создайте публичный репозиторий `MONOLITH` в организации `ISB-Technologies`.
2. Загрузите содержимое этой папки в корень репозитория и отправьте коммит в ветку `main`.
3. Откройте **Settings → Pages** и выберите в качестве источника ветку `main` и каталог `/ (root)`.
4. После публикации адрес сайта будет `https://isb-technologies.github.io/MONOLITH/`.
5. Если организация ограничивает GitHub Pages политиками, владелец организации должен разрешить публикацию для репозитория.

Файл `.nojekyll` отключает обработку Jekyll; сервер и сборка npm не нужны.

## Формат проекта

Экспорт JSON содержит `schemaVersion`, профиль, параметры в метрических единицах, состояние визуальных слоёв и предупреждение об ограничениях. Формат экспериментальный и может измениться до версии 1.0.0.
