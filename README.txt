MONOLITH BUILDER — Prototype 0.1

Run:
1. Extract the ZIP archive.
2. Open index.html in a modern browser. No server required.

The prototype is self-contained: all HTML, CSS and JavaScript live in
index.html, so it works offline (system fonts are used; no external
JavaScript libraries or CDNs are required).

Included test profiles:
HOTEL, DATA, RESEARCH, HQ, INDUSTRIAL, SHELTER.

Controls:
- Adjust above-ground floors, basements, grid dimensions, grid step, floor height.
- Change facade style and toggle visibility layers (frame, facade, slabs, core, basement).
- Rotate the model with the ⟳ button; toggle labels with Aa.
- Export/import project configuration as JSON.

Limitations:
This is an experimental conceptual 3D prototype. It is not a BIM application and does not calculate structural safety, foundations, fire code, evacuation, MEP systems, or regulatory compliance. Dimensions and profile defaults are illustrative only.
